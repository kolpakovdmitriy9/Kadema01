# Axion Studio

A landing page for Axion Studio, a design agency, built with React, Vite, and Tailwind CSS.

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS
- [`shaders`](https://www.npmjs.com/package/shaders) for the animated hero background
- [`lucide-react`](https://www.npmjs.com/package/lucide-react) for icons

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
